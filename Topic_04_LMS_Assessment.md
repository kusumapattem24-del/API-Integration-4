# Topic 4 - N8N LMS Assessment
## API Authentication and Security

## 1. Assessment Overview

This assessment evaluates your ability to implement secure API authentication mechanisms in n8n workflows using Basic Authentication, API Keys, Bearer Tokens, OAuth 2.0, and JWT while following security best practices and credential management.

## 2. Assessment Objective

Demonstrate your ability to configure reusable credentials, authenticate API requests securely, manage OAuth 2.0 connections, decode JWTs, and implement secure API integrations in n8n.

## 3. Prerequisites

- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–3.
- Access an active n8n instance.
- Have access to an OAuth-enabled API provider or mock service.

## 4. Assessment Tasks

- Exercise 1 – Create reusable encrypted credentials in n8n.
- Exercise 2 – Configure Basic Authentication, API Key Authentication, and Bearer Token Authentication.
- Exercise 3 – Configure OAuth 2.0 credentials and complete the authorization flow.
- Exercise 4 – Decode a JWT, validate authenticated API requests, and apply API security best practices.
- Exercise 5 – Record a demo video, upload the workflow/source code, and submit all deliverables through the LMS.

## 5. Practical Assessment Checklist

- [ ] Reusable credentials created
- [ ] Basic Authentication configured
- [ ] API Key authentication configured
- [ ] Bearer Token configured
- [ ] OAuth 2.0 connected
- [ ] OAuth authorization completed
- [ ] JWT decoded
- [ ] Authenticated API requests verified
- [ ] Security best practices followed
- [ ] Workflow executed successfully

## 6. Assessment Success Criteria

- Configure reusable encrypted credentials.
- Implement Basic Auth, API Key, Bearer Token, and OAuth 2.0.
- Decode and interpret JWTs.
- Execute authenticated API requests successfully.
- Apply credential security best practices.
- Submit all required deliverables.

## 7. Required Deliverables

- Loom/YouTube Demo Video – Mandatory
- GitHub Public Repository or Exported n8n Workflow – Mandatory
- Complete Workflow/Source Files – Mandatory
- Screenshots of credentials, authenticated requests, OAuth status, and JWT decoding – Mandatory
- Supporting Documentation (PDF/DOCX) – Optional
- Description / Additional Comments – Recommended

## 8. Submission Guidelines

Submit a Loom/YouTube walkthrough demonstrating all authentication methods, OAuth setup, JWT decoding, authenticated API requests, and workflow execution. Include the exported workflow or GitHub repository, screenshots, and any assumptions or challenges.
